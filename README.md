# EventPulse
EventPulse is a REST API for managing events, users, registrations, categories, and event announcements.
# Some Of The Features
- User registration and login
- JWT authentication
- Role-based authorization for admins and attendees
- Event filtering by category, city, and date
- Event search
- Pagination and sorting
- Event registration and cancellation
- Socket.io real-time announcements
- Central error handling
- Automated tests
- MongoDB Atlas database
